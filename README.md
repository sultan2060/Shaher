# 🚀 منصة تحليل الأسهم الأمريكية - Shaher

## 📊 وصف المنصة
منصة متقدمة وحديثة لتحليل الأسهم الأمريكية بيانات حية مباشرة من أسواق أمريكا. تتميز الواجهة بالوضوح والسهولة مع عرض مشارك وشامل لجميع المؤشرات والأهداف.

## ✨ المميزات الرئيسية

### 📈 الأسهم المدعومة (10 أسهم)
- **SPX** - مؤشر S&P 500
- **TSLA** - Tesla
- **MU** - Micron Technology
- **META** - Meta (Facebook)
- **AAPL** - Apple
- **GOOGL** - Google
- **MSFT** - Microsoft
- **AMZN** - Amazon
- **NVDA** - Nvidia
- **NFLX** - Netflix

### ⏰ الفترات الزمنية الشاملة
- 1 دقيقة
- 5 دقائق
- 15 دقيقة
- 30 دقيقة
- 60 دقيقة
- 1 ساعة
- 4 ساعات
- 12 ساعة
- 24 ساعة (يوم)
- أسبوع واحد

### 🎯 مستويات الأهداف والتداول
- 🛑 **وقف الخسارة** (Stop Loss)
- 🔴 **الدعم** (Support Level)
- ⚫ **نقطة المحور** (Pivot Point)
- 🟢 **المقاومة** (Resistance Level)
- 📍 **3 أهداف متتالية** (Target 1, 2, 3)

### 📊 المؤشرات والإحصائيات
- متوسطات متحركة (5، 20، 50 يوم)
- الانحراف المعياري
- نسبة الحجم
- مستويات التقلب
- ATR (Average True Range)

### 🔄 التحديث التلقائي
- تحديثات حية كل دقيقة
- تحكم كامل بسرعة التحديث (30-300 ثانية)
- عداد التحديثات
- قياس وقت جلب البيانات

### 📥 خيارات التصدير
- تحميل البيانات بصيغة CSV
- أسماء ملفات مع الوقت والتاريخ

- الأهداف محسوبة بناءً على التقلب الحالي
- استخدم المستويات كمرجع وليس نصيحة استثمارية
- التحديثات التلقائية تحتاج إلى اتصال إنترنت مستقر
